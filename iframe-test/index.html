Adres względny wobec tej strony lub pełny adres HTTP(S). Używaj tylko zaufanych stron.

2. Ustaw rozmiar iframe

Możesz też przeciągnąć prawy dolny narożnik ramki. Zmiana rozmiaru nie przeładowuje gry.

Jak testować?
  • Uruchom serwer lokalny z głównego katalogu projektu, np. przez Live Server w VS Code, i otwórz /iframe-test/.
  • Rozmiary oznaczają rzeczywisty obszar iframe w pikselach CSS. Podgląd nie jest skalowany — większa ramka wymaga przewijania.
  • Kliknij wewnątrz gry, aby przekazać jej sterowanie klawiaturą.
  • Rozmiar telefonu nie emuluje dotyku ani przeglądarki mobilnej. Do tego użyj trybu urządzeń w narzędziach przeglądarki.
  • Ramka nie ma sandboxa: lokalne gry zachowują dostęp do pamięci i funkcji przeglądarki tak jak przy zwykłym osadzeniu.
  • Zewnętrzna strona może blokować osadzanie przez CSP lub X-Frame-Options. Szczegóły błędów sprawdzisz w konsoli przeglądarki.
  • Jeżeli API gry blokuje lokalny adres przez CORS, uruchom tester na domenie dozwolonej przez API. Tester nie omija tych ograniczeń.

Strona jest otwarta z dysku. Uruchom ją przez serwer HTTP, aby poprawnie testować ładowanie zasobów i funkcje gier.
